🐱🐭 Cat and Mouse Game

A browser-based interactive Cat and Mouse game developed using modern web technologies.
The game demonstrates real-time interaction, user input handling, and dynamic game logic within a clean and responsive interface.

🎮 Project Overview

The Cat and Mouse Game is an interactive browser game where the player controls a character and competes against the opposing character through movement and collision mechanics.

This project highlights:

Game logic implementation

Event handling and keyboard interaction

Dynamic rendering

Collision detection

Clean and organized project structure

The game runs entirely on the front end with no backend dependencies.

✨ Features

🎮 Interactive gameplay

⌨️ Keyboard-controlled movement

⚡ Real-time character position updates

🧠 Collision detection logic

🔁 Restart / replay functionality

📱 Responsive design

🎨 Simple and intuitive interface

🚀 Installation & Running the Project
1️⃣ Clone the Repository

cd Cat-and-Mouse-game
2️⃣ Run the Game

If this is a standard HTML/CSS/JavaScript project:

Open index.html directly in your browser.

No additional installation is required.

If This Is a React Version

If the project uses React:

npm install
npm start

Then open:

http://localhost:3000
